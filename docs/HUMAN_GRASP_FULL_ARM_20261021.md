# 示范抓取接入固定全臂：原位搜索与物理执行

本阶段将上一轮手部抓取验证接到实际固定臂。目标模式是
**transferable task generation**，输入仍是合成示范回归中的 primitive 箱体，
不是 HumanEgo 真实数据。原 YAM + Sharpa 的箱体抓取举升通过；
高箱体未完成全臂执行，G1/G2 缺少同任务证据，整体完成为 **false**。

## 先验失败与原位修复

通过 `stage_on_bench` 复用原 `setup/scene.xml`，明确使用单位 rig 变换，
保留原固定安装位置、对象位置与尺度。`hand_scene_from_recon` 生成对应抓取场景。
物理执行模型为 56 个机器人关节加 7 个对象自由体坐标，共 63 qpos；
规划时的自由腕部不进入最终固定臂物理模型。

上一轮手部已通过的候选并不能直接执行：箱体两个候选在 80 mm 接近位姿的
位置误差为 85.56/84.54 mm、旋转误差约 60.6°，并出现手与前臂重叠；
高箱体候选误差为 145.90 mm/74.63°。这些是被拒绝的 IK 投影，
不是实际执行中的碰撞。没有降低阈值或移动机器人来规避失败。

箱体复用 `optimize_grasp_pose(family="rigid")`，同时传入原 `bench_scene`
及对象的 60/100/150 mm 举升目标，每段八个筛查采样。搜索固定
seed `20261021`，预算 `max_evals=64, iterations=4, population=16,
max_starts=6, workers=2`，以先前手部候选为起点。
18 次评估中 7 次因手臂筛查被拒、8 次因静态筛查被拒，3 次进入物理测试且通过。
三个候选分别独立重跑可达筛查、默认举升和默认持续握持，均通过。

这次重新生成了适合实际手臂的抓取姿态，不是对人类轨迹逐点忠实回放。
有限 IK 搜索失败也不代表所有抓取方式均不可达。

## 实际执行结果

`execute_subgoal_plan` 在固定法兰模型中，从原 home 状态执行一次
`grasp_lift`，路径依次举升 60/100/150 mm。
执行器实际选中生成的三指抓取姿态。

| 指标 | 实测 |
|---|---:|
| 记录帧 / 时长 | 174 / 5.8 s |
| 对象实际举升 | 153.5 mm |
| 手内位移 / 旋转滑移 | 1.7 mm / 1.897° |
| 执行中最大手/对象穿透 | 0.15 mm |
| 右臂峰值速度 | 81.17°/s |
| 隐式重置 / 时长重试 | 0 / 0 |

成功判据沿用现有默认值：举升至少 75 mm、对象在手内、滑移和动力学检查通过。
153.5 mm 是测量结果；不能把默认通过解释成精确 150 mm 跟踪。

六项独立审计均通过：`rigid_arm_hand_check`、`physics_recording_check`、
`swept_collision_audit`、`object_visual_penetration_audit`、
`contact_impulse_spike_audit`、`held_object_slip_audit`。
主代理再次重放全部 2,883 个物理子步，qpos/qvel 的最大重放误差均为零。
执行器实际选中的 pose 和实际起始 hand scene 绑定 SHA 后重新进行默认
举升与握持双验收，均通过。该独立手部压力测试的最大接触穿透为 1.589 mm，
与上表全臂轨迹的 0.15 mm 属于不同实验，不混用。

完整数值、初始失败、输入摘要及产物哈希见
[full-arm-validation.json](references/humanego/full-arm-validation.json)。
本机原始证据在 `.workbench/previews/human-grasp-full-arm-20261021/`，
保留初始筛查、优化调用、执行计划、真实场景、轨迹和独立审计。
实验记录的是启动 HEAD 和所用工作树源码哈希，不能视为干净提交的快照运行。

## 修复候选筛查丢失控制差异

此前 `screen_poses` 把 1 mm / 1° 内的重复腕部姿态标记为不可用重复项。
后续执行因此丢弃同姿态但压紧量不同的候选，上一轮箱体靠压紧量修复的结果
就可能无法进入完整机器人执行。

现在仅对**完全相同的几何筛查输入**复用计算结果，仍保留每个候选的索引与控制参数。
报告用 `kinematic_reuse_of` 表达计算复用；失败结果也保留原始失败证据。
相近但不相同的几何独立求解，避免把容差边界两侧的结果混用。
两类抓取生成器同步保留新字段，并移除失效的重复项排序分支。

这里复用的是离散几何可达检查，不能代替不同控制参数的物理验证。
实际规划、连续路径碰撞、握持及执行验收仍按原流程运行。
新测试覆盖同姿态不同压紧/张开量、0.5 mm 几何差异、失败复用的深拷贝、
无效候选后的正确索引。与起始状态、对象路径测试合计 11 项及 5 个子测试通过；
现有实际碰撞筛查脚本另有 13 个检查全部通过。

## 可移植全臂回归

新增 `tool_library/tests/test_human_grasp_full_arm.py`，只读取已提交 fixture 中的
原始失败种子和 primitive 参数，不读取上述本机成功姿态或轨迹。
测试从搭建同一安装位置的场景开始，确认原先验失败，再调用现有优化器重新搜索，
独立复验所有通过候选，执行固定全臂，核对选中姿态及起始场景 SHA，
重跑选中姿态双验收及六项物理审计。

实测 **1 passed in 169.34 s**：19 次评估、2 个进入物理测试并通过的候选，
最终同样得到 153.5 mm 举升、1.7 mm 滑移。这与上面从已修复手部候选出发的
18 次评估实验输入不同，分别记录。首次测试在 MJCF 四元数序列化精度断言处失败；
将该新断言改为 1e-6 容差以覆盖约 2.07e-7 的保存舍入误差，所有物理阈值保持不变。

```bash
MUJOCO_GL=egl OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  .workbench/venv/bin/python -m pytest -q \
  tool_library/tests/test_human_grasp_full_arm.py
```

该测试仍只证明原 YAM + Sharpa 的合成箱体抓取举升，不产生三本体通过结论。
